SamuelClient 是一款 Minecraft 启动器，面向需要管理原版、Fabric 与 Forge 实例的玩家，在同一个桌面工作区中整合账号、模组、整合包、Java 运行时与 MatchCore 对局交接。

## 为什么选择 SamuelClient

- **整合包随行。** 搜索 Modrinth 整合包、导入本地 `.mrpack`，并在启动前修复缺失文件。
- **按你的方式管模组。** 导入本地 JAR，或为已安装的 Fabric、Forge 配置发现 CurseForge 与 Modrinth 模组。
- **选对 Java。** 跟踪已安装运行时，并为每个配置单独选择默认版本。
- **使用你的账号。** 离线与 Armorial 登录流程，支持不同的游戏方式。
- **验证后再更新。** 签名 OTA 清单与 SHA-256 下载校验共同保障更新来源。
- **顺畅进入 MatchCore。** 接收 Arena 交接，并使用所选账号启动指定对局。

## 兼容性与限制

0.3.2 版仅提供 Linux amd64 与 Windows amd64 构建；不支持 macOS、NeoForge、Quilt 与 CurseForge 整合包。
